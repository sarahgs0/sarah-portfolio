Scientific & Academic Projects

Helios: Energy for All

Helios combined an Arduino solar tracker that used light sensors to guide a servo motor with a six-page article on unequal solar energy access, a seven-page educational website, and a policy proposal for tax incentives and low-income household support. I programmed the prototype, wrote the article, built the website, and developed communication materials. Ceará Científico invited Helios as one of six robotics projects selected statewide.

  • Arduino
  • Solar access
  • Public policy

Sustainable Cities

This project explored sustainable urban development through a comparison between China's sponge cities and Brazilian urban environments. I examined how cities can better manage rainwater, reduce flooding, and incorporate environmentally responsible infrastructure. As a practical component, I built a model of an ideal sustainable city using recycled materials, bringing together the concepts explored during the research.

  • Urban sustainability
  • Sponge cities

Programming & Technology Projects

ViaCEP API Data Collector

During my programming internship, I built a Python application that retrieves Brazilian postal code data from ViaCEP. It uses the Requests library to call the REST API, handles errors, and processes the JSON response. The application then exports the resulting records to CSV so they can be reviewed separately from the API response.

  • Python
  • Requests · REST API
  • JSON → CSV
